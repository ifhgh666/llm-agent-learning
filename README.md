# LLM Agent Learning System

A minimal LLM Agent framework built with Python, DeepSeek API, and the OpenAI Python SDK.

This project is created for learning the core mechanisms behind LLM Agents step by step, including **Function Calling**, **Tool Registry**, **dynamic tool execution**, and **Agent Loop**.

---

## Overview

This project demonstrates how a Large Language Model can go beyond simple text generation and interact with external Python tools.

The Agent can:

1. Understand user requests
2. Decide whether a tool is needed
3. Select the appropriate tool
4. Generate tool arguments
5. Dynamically execute Python functions
6. Return tool results back to the LLM
7. Continue reasoning after tool execution
8. Call additional tools when necessary
9. Stop automatically when the task is complete
10. Prevent infinite execution using a maximum step limit

Core Architecture

The project separates the Agent into several responsibilities.

main.py

Responsible for:

Receiving user input
Sending messages to the LLM
Detecting tool calls
Executing the Agent Loop
Returning tool results to the LLM
Limiting the maximum number of execution steps
tools.py

Contains the actual Python functions used by the Agent.

Example:

def calculate_bmi(weight, height):
    bmi = weight / (height ** 2)
    return f"BMI指数是{bmi:.2f}"
tool_registry.py

Maps tool names generated by the LLM to real Python functions.

Example:

tool_map = {
    "get_weather": get_weather,
    "get_stock_price": get_stock_price,
    "calculate_bmi": calculate_bmi,
    "search_recipe": search_recipe,
    "loop_test": loop_test
}

This avoids writing many hard-coded if / elif statements.

Agent Loop

The Agent does not stop immediately after the first tool call.

Instead, it continues executing until:

The LLM no longer requests a tool, or
The maximum number of execution steps is reached

Example:

max_steps = 10

for step in range(max_steps):
    ...

This prevents the Agent from running forever if the model repeatedly calls tools.

Tool Registry

Earlier versions of the project used hard-coded tool routing:

if tool_name == "get_weather":
    ...
elif tool_name == "calculate_bmi":
    ...

The current version uses a Tool Registry:

tool_function = tool_map.get(tool_name)

result = tool_function(**args)

This makes the Agent easier to extend and maintain.
